# 每項 Robustness Challenge 都有獨立 Evidence

九項必要 challenges 各自發布不可改寫的 artifact，並綁定同一 candidate、Historical Evaluation data snapshot、fold inventories、成本政策與 qualification spec；使用隨機性的 challenge 還必須預先固定 seed。Validator 要求 challenge ID 集合剛好完整且唯一，任一缺失、binding 不一致或 gate 失敗都使 Study `fail`，避免以單一摘要掩蓋未執行或失敗的挑戰。
