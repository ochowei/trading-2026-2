# 強制單一 Study State Machine 與明確提前終止路徑

正式順序固定為 Study creation、preregistration approval、Development authorization、Trials、registry freeze、provenance audit、candidate freeze、Historical Evaluation、九項 challenges、retrospective replay、independent review、terminal。只有 trial budget 用盡、provenance disposition、正式 gate failure 或不可判定的完整性問題可以提前終止；可恢復技術問題只進入 `paused` 並回到原階段，不得跳關。
